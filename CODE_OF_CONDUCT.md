# Code of Conduct

This project expects respectful, technical collaboration.

## Expected Behavior

- Discuss ideas and changes on their technical merits.
- Be clear about evidence, assumptions, and uncertainty.
- Respect different experience levels and tool setups.
- Keep feedback actionable.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.
- Misrepresenting project behavior or verification results.

## Enforcement

Maintainers may remove comments, close discussions, reject contributions, or block participants who violate this code. Reports should include the relevant links, context, and screenshots or logs when possible.
